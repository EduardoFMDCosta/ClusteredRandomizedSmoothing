\subsection{Adversarial attack}
\label{sec:uav3d-attack}

\paragraph{Threat model.} The attacker perturbs the \emph{observation}, not the
physical state. At step $t$ the controller consumes $\Phi(s_t) + \delta_t$, where
$\Phi$ is the fixed per-axis normalisation and $\|\delta_t\|_2 \le \epsilon$,
while the environment evolves from the uncorrupted $s_t$. This is the same input
space the smoothing integrates over, so $\epsilon$ and the smoothing scale
$\sigma$ are comparable and we report $\epsilon/\sigma$ throughout. The
perturbation is recomputed every step, and each branch is attacked white-box
against \emph{itself}, since a smoothing guarantee constrains only the smoothed
predictor.

Since $\Phi$ divides each coordinate by its natural scale --- the corridor
half-extents $15/9/7$\,m for the $x/y/z$ positions, the $\pm7$\,m\,s$^{-1}$ speed
limit for the velocities --- a normalised radius reads as a \emph{fraction} of
that scale, and quoting it in metres requires nominating an axis. Against
$x$-position, $\epsilon=\sigma=0.05$ is $0.75$\,m; other axes scale by their own
divisor.

\paragraph{Objective.} Writing $\pi_{\mathrm{def}}(\cdot\mid x)$ for the action
distribution a branch emits on observation $x$, the attacker solves
%
\begin{equation}
  \min_{\|\delta\|_2 \le \epsilon}\;
  \mathbb{E}_{a \sim \pi_{\mathrm{def}}(\cdot\,\mid\, \Phi(s_t) + \delta)}\bigl[Q(s_t,a)\bigr],
  \qquad
  Q(s,a) = \mathbb{E}_{w}\bigl[\, r(s,a,s'_w) + \gamma\, V^{\pi}(\Phi(s'_w)) \,\bigr],
  \label{eq:uav-attack}
\end{equation}
%
where $s'_w = As + Ba + w$ is the successor state and $V^\pi$ is the critic from
the PPO run that produced the policy. Only the dense progress reward is used,
%
\begin{equation}
  r(s,a,s'_w) = \tfrac12\bigl(\|\Pi s - g\| - \|\Pi s'_w - g\|\bigr) - 0.01,
  \label{eq:uav-reward}
\end{equation}
%
with $\Pi$ extracting the three position coordinates and $g$ the goal centre.

The reward leaves the expectation. The process noise enters only the velocity
coordinates, so $\Pi w = 0$ and $\Pi s'_w = \Pi(As + Ba)$ is deterministic given
$(s,a)$; hence $r(s,a,s'_w) = r(s,a)$ almost surely and
%
\begin{equation}
  Q(s,a) = r(s,a) + \gamma\, \mathbb{E}_{w}\bigl[V^{\pi}(\Phi(s'_w))\bigr].
  \label{eq:uav-q-split}
\end{equation}
%
The progress term is therefore exact, and the only expectation left is the one on
$V^\pi$, which we take by a product Gauss--Hermite rule with three nodes per noisy
axis. Evaluating the plug-in $V^\pi(\Phi(\mathbb{E}[s'_w]))$ instead would be
biased by the Jensen gap $\tfrac12\sigma_w^2\operatorname{tr}(\nabla^2 V^\pi)$
over the velocity block.

The discontinuous terminal branches of the environment reward ($\pm5$, $+10$) are
omitted; $V^\pi$ carries their value, having been fitted on returns containing
them, and dropping them is what makes \eqref{eq:uav-attack} differentiable. The
same $V^\pi$ scores all branches, so none faces an easier objective.

\paragraph{Differentiating each branch.} Two distinct objects carry the
perturbation, and both must respond to it. The \emph{policy gate}
$\omega_k(x)$, $k=1,\dots,K$, is the policy's own mixture over behavioural modes;
the \emph{mixture weights} $\rho_j(x)$, $j=1,\dots,k$, are the weights of the
\emph{smoothed controller's emitted} distribution, namely the fraction of sampled
actions falling in robustness region $j$. The second is downstream of the first
and indexed differently --- clusters are not numbered by policy component.

For the raw $K$-component mixture policy we keep $\omega_k$ analytic and
reparameterise only within components,
%
\begin{equation}
  \sum_{k=1}^{K}\omega_k(x)\,\frac1M\sum_{m=1}^{M}
  Q\Bigl(s_t,\;\zeta\bigl(\mu_k(x) + \Sigma_k(x)^{1/2}\varepsilon_{k,m}\bigr)\Bigr),
  \qquad x = \Phi(s_t)+\delta,
\end{equation}
%
with $\zeta = c\tanh$. The gradient then reaches the gate logits, so PGD can find
the perturbation that shifts mass \emph{between} modes rather than only dragging
both modes to a worse location --- precisely the failure the defence addresses.

A smoothed branch emits action $a_j(x)$ --- the $\alpha$-trimmed mean of cluster
$j$ over $N$ smoothing draws --- with probability $\rho_j(x)$, the single-cluster
baseline being $k=1$; the objective is therefore the mean over $M$ realisations of
$\sum_j \rho_j(x)\, Q(s_t, a_j(x))$. The same analytic treatment is unavailable
here, because $a_j$ is a non-linear function of the \emph{joint} set of $N$ draws,
so the gate expectation does not push inside it. We therefore draw the component
by a straight-through Gumbel-max step with noise fixed across the run: since
$\argmax_k(\log\omega_k + G_k)$ \emph{is} an exact categorical draw from $\omega$,
and scaling logits by a temperature cannot move an $\argmax$, the forward value is
an exact sample from the true gate at any temperature --- the temperature shapes
only the gradient. The weights $\rho_j$ are treated the same way: forward they are
the hard region occupancy the deployed controller emits, backward a softmax over
negated region distances. The $\alpha$-trimming itself needs no relaxation, as
\texttt{sort} propagates gradient through its permutation and the trimmed mean is
piecewise linear in its inputs.

Frozen at the clean anchor and treated as constants in the backward pass (BPDA):
the cluster \emph{geometry} --- centroids and regions --- whereas the executed
controller re-clusters at the perturbed input; the sorting permutation; and
cluster membership with the integer trim counts it determines. The objective is
consequently discontinuous in $\delta$ where the straight-through indices flip, so
the gradient is a relaxation and PGD a heuristic upon it; the values it compares
across steps and restarts are the exact ones.

\paragraph{Optimiser.} All noise --- smoothing draws, the Gumbel variates driving
the gate, and within-component noise --- is drawn once and held fixed across every
step and restart (expectation over transformation with common random numbers),
making the objective a deterministic function of $\delta$; with resampled noise
the gradient would measure sampling noise as much as slope. Deterministic is all
PGD needs here: the objective is not continuous, and the incumbent bookkeeping
compares exact values rather than following a smooth landscape. Each evaluation of the objective
averages $M=64$ such realisations. We then run $\ell_2$ PGD for $T=40$
gradient-\emph{normalised} steps of size $2.5\epsilon/T$, projecting onto the ball
after each step; the run is repeated from three starting points --- $\delta=0$ and
two draws uniform in the ball --- and we keep the best iterate over all of them.
Normalised rather than raw steps because $\|\nabla J\|$ varies by orders of
magnitude between the flat interior of a mode and the boundary between modes, and
the chosen size lets an iterate cross the ball about $2.5$ times over the run.
Since $\delta=0$ is both the first starting point and the initial incumbent, the
returned perturbation never scores worse than the clean input, and $\epsilon=0$ is
exactly a no-op. In practice the
budget binds, $\|\delta^\star\|_2=\epsilon$, unlike the random search over
candidate perturbations it replaces, which used roughly $62\%$ of the ball and
selected on few-sample estimates --- an arg-max that returns the luckiest
candidate rather than the worst perturbation.
